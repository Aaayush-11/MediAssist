# MediAssist

An AI-powered pharmacy benefits and prior authorization assistant built using Retrieval-Augmented Generation (RAG).

## Project Status

Under development.

## Planned Technologies

- Python
- FastAPI
- vLLM
- LangGraph
- Qdrant
- SQLite
- Docker

## Project Goals

- Retrieve relevant medication and prior authorization information.
- Combine semantic and keyword-based search.
- Provide structured formulary lookups.
- Generate grounded responses using an LLM.
- Apply safety guardrails and evaluate response quality.

## Data Policy

This project uses synthetic and publicly available data only. No protected health information (PHI) is used.
